# 📘 Yambamuz

> **L'élégance du savoir, la clarté de la découverte.**

**Yambamuz** est une plateforme web "Hub" minimaliste conçue pour centraliser l'apprentissage académique (Économétrie, Data Science, Mathématiques) et le divertissement au sein d'une interface épurée, calme et hautement intuitive. Inspirée par la simplicité de Google, elle privilégie la concentration et l'expérience utilisateur (UX).

---

## ✨ Vision du Projet

Dans un monde saturé d'informations, **Yambamuz** se veut être un sanctuaire de connaissance. L'objectif est d'offrir un environnement sans distractions pour :
* **Apprendre** : Des parcours structurés en économie et technologie avec supports PDF.
* **S'amuser** : Une fenêtre vers le divertissement intelligent et les jeux.
* **Contribuer** : Une plateforme participative pour faire grandir la base de connaissances.

---

## 🛠️ Stack Technique

Le projet utilise les dernières technologies de développement web pour garantir performance et fluidité :

* **Frontend** : [React.js](https://react.dev/) (pour une interface réactive).
* **Styling** : [Tailwind CSS](https://tailwindcss.com/) (Design épuré et responsive).
* **Icônes** : [Lucide-React](https://lucide.dev/) (Visuels fins et modernes).
* **Animations** : [Framer Motion](https://www.framer.com/motion/) (Transitions douces entre les vues).
* **Architecture** : Single Page Application (SPA) avec gestion d'états dynamiques.

---

## 📂 Architecture de la Plateforme

L'application est organisée en une navigation "profonde" pour éviter la surcharge visuelle :

### 1. L'Accueil (Le Focus)
Une page blanche centrée sur une **barre de recherche intelligente**. Trois boutons discrets permettent d'orienter l'utilisateur : *Apprendre, S'amuser, Contribuer*.

### 2. Le Hub "Apprendre"
Une organisation par domaines d'expertise :
* **Économétrie** : Intro, Données de Panels, Économétrie Spatiale.
* **Data** : Storytelling, Machine Learning, Data Engineering.
* **Maths & Stats** : Cours théoriques et exercices appliqués.
* *Chaque cours inclut un contenu rédigé et un support de cours téléchargeable.*

### 3. L'Espace "S'amuser"
Une galerie visuelle interactive redirigeant vers des contenus vidéos (YouTube) ou des mini-jeux pour la détente.

### 4. L'Espace "Contribuer"
Un centre de communication permettant aux utilisateurs de proposer des idées ou de contacter l'administrateur via un formulaire chic et simple.
